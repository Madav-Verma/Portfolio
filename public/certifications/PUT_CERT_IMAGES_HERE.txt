HOW TO ADD/REPLACE AN IMAGE: save your file as the number above (e.g. 13.png)
into this folder, then rebuild (npm run build). Cards without an image
gracefully fall back to text-only.

VERIFY LINKS: certificates with a public verification page (LinkedIn Learning,
Credly) are clickable — the "Verify" link appears on hover. To add more,
edit src/data.js and add `verify: 'https://...'` to the entry.
